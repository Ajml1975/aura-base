Bienvenido a AURA BASE

Diseña bases de datos relacionales en tu navegador y descarga el resultado como archivo SQLite .db.

Comienza con Nueva base o abre un archivo existente. Los datos no se suben a ningún servidor.

Consejo: descarga tu trabajo al terminar cada sesión. El almacenamiento de esta versión permanece en memoria hasta que exportes el archivo.

Vista del formulario

En vista de ficha puedes crear, modificar y eliminar registros. Guarda una copia .db antes de hacer cambios importantes. Los formularios de Access no se importan: se importan tablas y datos cuando el controlador lo permite.

Campos del informe

Los informes se generan desde tablas o consultas de selección guardadas. Utiliza Imprimir / PDF y selecciona «Guardar como PDF» en Windows.

Diseñador de macros · Nueva macro

Las macros son secuencias de acciones predefinidas. No ejecutan JavaScript ni SQL de modificación arbitrario.

Editor de código SQL · Nuevo módulo
